# Segurança / Security

## Português (BR)

Este é um projeto local. **Não publique configurações pessoais, tokens, chaves, arquivos de autenticação, histórico de sessões nem STATUS.md reais.** Os scripts de diagnóstico mostram versões e marcadores de integração, não credenciais.

A instalação de hooks é desativada por padrão e requer `-Apply`. Backups são mantidos localmente. O Context Guard não cria permissões, não abre agentes automaticamente, não envia dados à rede e não encerra processos. Checkpoints podem conter nomes de arquivos do Git e caminhos privados.

Se identificar uma vulnerabilidade, comunique-a de maneira privada ao mantenedor do futuro repositório antes da divulgação pública. Não abra issues com credenciais ou material sensível.

## English

This is a local-first project. **Do not publish personal configurations, tokens, keys, auth files, session histories or real STATUS.md checkpoints.** Diagnostic scripts print versions and integration markers, not credentials.

Hook installation is preview-only by default and requires `-Apply`. Backups stay local. Context Guard does not elevate privileges, auto-launch agents, send data to the network or terminate processes. Checkpoints may still contain Git filenames and private paths.

Report security vulnerabilities privately to the repository maintainer before public disclosure. Never open an issue containing credentials or sensitive materials.
